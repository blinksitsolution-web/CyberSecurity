# Protocol reference sheet

## Goal

Match common protocols and ports to layers, then keep a sheet you can use when a log mentions a port. Thursday's practical is this sheet. It is a reference, not a list of targets.

## What was built

`protocols.csv` lists protocols a SOC beginner actually meets, including the lab ports for SSH, RDP, and the Wazuh agent. The SOC note says why the port matters in a log.

## How to reproduce

1. Read the sheet once with the OSI and TCP/IP models beside you.
2. Add rows you meet in class. Do not delete the source column: `reference` means this starter sheet, `observed` means you saw it in your lab.
3. When you are unsure of a port, check a current vendor document rather than guessing.
