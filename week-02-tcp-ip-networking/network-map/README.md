# Network map

## Goal

Draw a small network and trace one packet from a laptop to a service. Friday's lab asks you to diagnose addressing and packet flow. The map can be the home lab, a classroom, or both, as long as you label which parts you observed and which parts you designed.

## What was built

`network-map.md` has a starter diagram for the home lab and a packet-trace table. The diagram is a design, not a claim that your virtual machines already exist.

## How to reproduce

1. Redraw the diagram so it matches the network you actually have. Delete any box you have not built.
2. Pick one packet, such as a browser opening a site, or your Windows VM talking to the Wazuh server later in the bootcamp.
3. Fill the hop table with what you know. Write "not observed yet" where you have not captured traffic.
4. Do not run a scan of a network you do not own. Drawing and reading your own lab is enough.
