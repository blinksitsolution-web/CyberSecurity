# Incident-response notes

## Goal

Practise the decisions at the start of an incident: triage, contain, preserve evidence, tell the right person, and recover. Monday's lab is this. Use the Week 4 tabletop if you want a story, and use Week 11's parser if you want a log. Label which one you used.

## What was built

`ir-playbook.md` is a short playbook for the home lab. It is not a company procedure, and it does not contain attack steps. Containment options are defensive: isolate a VM, disable an account you control, keep the logs.

## How to reproduce

1. Walk one synthetic alert from Week 11 through the playbook, or one alert you exported from your Wazuh dashboard.
2. Write the decision at each phase.
3. If you are using the sample log, write **PRACTICE DATA** at the top of your notes so a reader cannot confuse it with an incident on a real network.
