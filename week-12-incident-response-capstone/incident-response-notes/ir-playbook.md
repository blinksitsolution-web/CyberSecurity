# Home-lab incident playbook

Data label for the walkthrough you are doing: [PRACTICE DATA or my-lab]

## Phases

| Phase | Question | Your decision this time |
| --- | --- | --- |
| Triage | What does the log actually show, and how many times? |  |
| Severity | Who is affected, and is admin access involved? |  |
| Contain | Can you disconnect the VM from the host-only network, or disable the lab account, without destroying logs? |  |
| Preserve | Which file, export, or snapshot will you keep? |  |
| Notify | Who needs to know? For this bootcamp, that is your trainer, not a public channel. |  |
| Eradicate | What change removes the access: a password reset, an account removal, a rebuilt VM from a snapshot? |  |
| Recover | What did you restore, and how did you check it? |  |
| Learn | Which detection or control would have made this shorter? |  |

## Orders you will not give

- Do not wipe a disk as a first step. You will delete the evidence.
- Do not test back against an address to "see who it is".
- Do not post raw logs that contain personal data.
