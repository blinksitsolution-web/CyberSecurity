# Incident report

## Goal

Write an incident report with a timeline, impact, and what changed afterwards. The template is for your lab. If the only events you have are the Week 11 samples, the report must say **PRACTICE DATA** in the banner so you do not present a teaching file as a breach.

## What was built

`incident-report.md` is the template. Every factual field is blank.

## How to reproduce

1. Copy the banner's label to the right value before you write anything else.
2. Build the timeline from lines you can point to. A time without a source does not go in.
3. Separate what you know from what you think.
4. Close with lessons that map to a control in this repository: a Sigma rule, a backup test, a missing MFA setting, or a scope gap.
