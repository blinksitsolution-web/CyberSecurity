# Role-play audit

## Goal

Practise gathering evidence and explaining a finding without overstating it. Wednesday's lab is the role play: one person asks, one person shows evidence, one person writes the finding.

## What was built

`audit-findings.md` is the working paper. It includes the questions an auditor can ask about this repository, and an empty findings table.

## How to reproduce

1. Swap roles at least once so you have asked and answered.
2. Choose two controls from the gap checklist.
3. Write what evidence you were shown. If the evidence was missing, the finding is a gap in evidence, which is still a real finding.
4. Do not upgrade "the document exists" into "the control operates" unless you saw it operate.
