# ISO 27001 gap check

## Goal

Compare evidence you actually have with a short control checklist. Tuesday's practical is "Spot the Gap". ISO/IEC 27001 is the management-system standard. The 2022 edition groups Annex A controls into organisational, people, physical, and technological themes.

## What was built

`gap-checklist.csv` lists 16 study topics paraphrased in plain language. It is not the text of the standard, and completing it does not certify anyone. Every status starts as `not-reviewed`.

## How to reproduce

1. For each row, look for evidence in this repository or on your VM: a policy note, a screenshot, a checklist, or nothing.
2. Set status to `met`, `partial`, `gap`, or leave `not-reviewed`.
3. If you mark `met`, the evidence column must name a file you can open. Otherwise move it back.
4. The Week 11 script can count a copy of this style of sheet. It will not upgrade a guess into a pass.

Buy or borrow the official standard if your trainer wants clause numbers. Do not paste the standard into this repository.
