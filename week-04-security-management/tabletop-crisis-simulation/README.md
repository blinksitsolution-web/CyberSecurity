# Crisis tabletop

## Goal

Rehearse decisions, roles, and escalation in a discussion. You do not attack a system to complete this exercise. Thursday's lab is the simulation. The decision log is the assignment.

## What was built

- `scenario.md` — a fictional lab incident you can run in under an hour.
- `decision-log.csv` — one row per decision. It starts empty.

The story uses the same kind of signals as the Week 11 sample detections, but it is still a story. Do not file it as a real incident.

## How to reproduce

1. Assign the roles in the scenario. Five people is enough. Fewer people can hold two roles.
2. Read inject 1. Talk. Write the decision before you read inject 2.
3. Stop at containment and communication. Do not add technical attack steps.
4. End with what you would want a log to prove, and which log you do not have yet.
