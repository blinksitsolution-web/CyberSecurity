# Risk assessment sprint

## Goal

Score likelihood and impact, then choose a treatment: mitigate, avoid, transfer, or accept. Monday's practical is the sprint. You already started the language in the Week 1 register.

## What was built

- `scoring-guide.md` — the 1–5 scale this folder uses, and how to write a treatment.
- `risk-assessment.csv` — columns for the sprint. Two rows show the shape of a finished line and are marked `example=yes`. The other rows are blank.

Scores in the example rows are teaching numbers for a fictional lab, not a measurement.

4. On Friday, be ready to explain one high score and one score you refused to invent.
