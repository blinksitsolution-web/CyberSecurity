# Bootcamp materials

Worksheets, study prompts, example rows, and small Python checks for the Maxim Nyansa cybersecurity bootcamp. They were the starting layout of this repository.

They are not submitted findings. Example rows are marked as examples. Checklists here are unticked. A recruiter reading the portfolio should use the week folders and [Yes You Can Cyber Secure](../yes-you-can-cybersecure/) section instead.

Week 1 files that already carry James Ackah-Blay's name (the personal learning plan, the careers map, and the lab checklist) are preserved in [week-01-foundations](week-01-foundations/). The prompts are still blank, so they stay in this folder rather than in the portfolio front.

The Python checks still run from the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest
```

Passing tests show that the scaffold code runs. They are not lab results from a virtual machine.
