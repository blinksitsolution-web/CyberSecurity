# System hardening report

## Goal

Turn the baseline and the audit into a short technical report. Friday's weekly submission is this report together with the checklist. The professional skill this week is writing findings so someone else can follow them.

## What was built

`hardening-report.md` is the report structure. Every finding slot is empty. Example wording shows the shape of a sentence without pretending a check was done.

## How to reproduce

1. Finish the checklist and at least one audit output.
2. Move only the rows you checked into the findings table.
3. For each gap, name the control, what you saw, why it matters, and the next step.
4. If you have not built a VM yet, submit the report with an honest "not run" status. Do not paste the unit-test output as if it were your server.
