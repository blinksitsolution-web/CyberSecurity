# Backups and logging

## Goal

Test a restore, and practise reading a log before you claim you have a backup or a detection. Thursday's practical is this evidence.

## What was built

`backup-log-checklist.md` is a procedure and a reading guide. It does not include a backup of your files. The Week 11 triage project is where sample logs are parsed. This week you decide what must be backed up and what a useful log contains.

## How to reproduce

1. Pick one small file on a VM, copy it with the tool you were taught, delete only the copy's destination test file, and restore it.
2. Record the commands you ran and whether the restored file matched.
3. Open one real log on a machine you own, or the synthetic `auth.log` in Week 11 if your VM is not built yet. Say which one you used.
4. Answer the log questions in the checklist. Quote a line you saw. Do not type a line you did not see.
