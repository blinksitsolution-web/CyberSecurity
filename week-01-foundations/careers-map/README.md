# Careers map

## Goal

See where blue-team work sits among cybersecurity jobs, and write the first version of your own path. The Friday session covers roles, the security auditor, and certifications. Week 8 returns to your CV.

## What was built

`careers.md` is a short map of roles that show up in this bootcamp, with a blank path for you. It does not invent a salary, an employer, or a certification you hold.

## How to reproduce

1. Read the role table.
2. Fill the "My path" section in your own words.
3. Name, LinkedIn, Medium, and email are already in `careers.md`. The rest of "My path" is still yours to write.
