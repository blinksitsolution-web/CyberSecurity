# Secure development checklist

## Goal

Map security work onto the life cycle instead of leaving it for the last Friday. Monday's assignment is this checklist.

## What was built

`sdlc-checklist.csv` has one row per phase. The status column starts at `not-started`. The example tasks are things this bootcamp already asks you to do.

## How to reproduce

1. Read each phase and tick a status only when you can point at work: `not-started`, `drafted`, or `done`.
2. Add a row if your trainer uses a phase name you do not see here.
3. Bring the checklist to the Friday review.
