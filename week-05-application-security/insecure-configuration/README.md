# Insecure configuration

## Goal

Review application settings and access restrictions. Thursday's assignment is this findings sheet. Default passwords, debug pages, and wide-open admin paths are configuration problems even when the code's input checks are fine.

## What was built

`config-checklist.csv` is a review list for a fictional training app called "Ticket Desk". Every row starts as `not-reviewed`. There is no live app and no discovered vulnerability behind the list.

## How to reproduce

1. Use the list in class when you look at the training sandbox your trainer provides.
2. Mark a row only after you have looked. `not-present` is a valid result.
3. Carry any real gap into the Friday review report as something you saw, with the sandbox name.

Do not turn this list into a scan of a public website.
