# Cloud security checklist

## Goal

Review one cloud service against a short checklist and present the treatments on Friday. If you do not want to open an account, review a named service on paper and say that no account was created.

## What was built

`checklist.csv` starts at `not-reviewed`. The rows cover identity, logging, data location, exposure, and backup. None are pre-ticked.

## How to reproduce

1. Name the service in the first rows you fill, in the notes.
2. For each control, record what you saw in the service's own settings or documentation.
3. A control you could not see is `not-reviewed`, not `met`.
4. Move the gaps into the cloud risk register as risks with owners.

Do not create public buckets, open security groups, or test someone else's tenant to complete the list.
