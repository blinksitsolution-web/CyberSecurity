# Cloud risk register

## Goal

Build a risk register for one selected cloud service. Thursday's practical is this register. Friday you present the treatments.

## What was built

`cloud-risk-register.csv` has two teaching rows for a fictional decision, "a class uses a shared SaaS mailbox", marked `example=yes`. Blank rows are for the service you actually reviewed. Example scores are not measurements.

## How to reproduce

1. Set `service_reviewed` on your rows to the same name you used on the checklist.
2. Score with the Week 4 guide.
3. Every `mitigate` row needs a control you can point at on the checklist.
4. If the review was on paper, set `account_opened` to `no`.
