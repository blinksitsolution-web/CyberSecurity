# Week 9 — Cloud computing and cloud security

**30 November–4 December 2026.** Professional session: interview preparation and portfolio building. The root README of this repository is the page you can show.

Topics: public, private, and hybrid cloud; SaaS, PaaS, IaaS, SECaaS, and IDaaS; shared responsibility and cloud risks.
