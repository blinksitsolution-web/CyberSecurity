# Authorised-test review

## Goal

Compare tools and document the human review for the Friday session on AI and authorised offensive tests. The bootcamp asks you to automate offensive tests inside a sandbox you are allowed to use. This public portfolio does not contain that automation, those commands, or a model prompt that asks for them.

## What was built

`human-review.md` is a decision record: scope, what you refuse to automate, what a tool might draft, and what you must check by hand. You can attach class notes that your trainer said were safe to store. You should not attach exploit output.

## How to reproduce

1. Re-read the Week 10 scope. If it is unsigned, this review stays a plan.
2. Fill the decision record with the tool categories you were shown in class. Names of categories are enough.
3. Write one task an AI draft is good at (summarising your own notes) and one task you will not hand to it (choosing a target, or running a test).
4. Stop. Do not add scripts that perform the test.
