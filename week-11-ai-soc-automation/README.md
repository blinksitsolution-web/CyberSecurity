# Week 11 — AI and cybersecurity automations

**14–18 December 2026.** Professional session: presentation skills and capstone documentation.

Topics: using automation, including AI tools, across governance, defence, incident response, behaviour, threat intelligence, and authorised testing. The point of the week is to see what a script or a model is good at, and where a person still has to decide.

The timetable also asks you to automate offensive tests inside an authorised sandbox. This portfolio does not ship that automation. The [authorised-test-review](authorised-test-review/) folder is the human-review record instead. Exploit scripts do not belong in a beginner portfolio that will be public.
